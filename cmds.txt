Here are the exact Docker commands to **clear the build cache (while keeping all downloaded base images like PostgreSQL, MongoDB, Judge0, etc. intact)** and rebuild your containers cleanly:

---

### 1. Step-by-Step Clean & Rebuild

```powershell
# Step 1: Remove old build cache (does NOT delete downloaded base images)
docker builder prune -f

# Step 2: Stop and remove stale/orphan containers and networks
docker compose --profile engines down --remove-orphans

# Step 3: Rebuild your application images fresh (without cache)
docker compose --profile engines build --no-cache

# Step 4: Start all services and engines in the background
docker compose --profile engines up -d
```

---

### 2. Or Run Everything in One Shot (Copy & Paste)

```powershell
docker builder prune -f; docker compose --profile engines down --remove-orphans; docker compose --profile engines up -d --build --force-recreate
```

---

