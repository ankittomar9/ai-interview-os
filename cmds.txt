# AI Interview OS — Fast Development & Build Guide

### ⚡ The 5-to-10-Second Fast Refresh (Recommended)

You **never** need to download JARs or wipe Docker caches when modifying code. Use the new rapid refresh script:

```powershell
# 1. Refresh only the service you edited (takes ~5-8 seconds):
.\scripts\dev-refresh.ps1 interview-session-service
.\scripts\dev-refresh.ps1 evaluation-report-service
.\scripts\dev-refresh.ps1 ai-orchestrator-service
.\scripts\dev-refresh.ps1 api-gateway-service
.\scripts\dev-refresh.ps1 frontend

# 2. Or refresh all modified backend microservices incrementally (takes ~15-20s):
.\scripts\dev-refresh.ps1
```

---

### 🛠️ Manual 2-Step Refresh (Without the Script)

```powershell
# Step 1: Package only the touched module (uses host ~/.m2 cache, ~5s):
mvn package -pl interview-session-service -DskipTests

# Step 2: Recreate only that container in Docker (~3s):
docker compose up -d --no-deps --build interview-session-service
```

---

### 🚫 Why the Old Command Took 10–15 Minutes:

1. **`docker builder prune -f`**: Purged Docker's entire layer cache, forcing Docker to download all npm packages for `frontend` and re-run all base layers from the internet every time.
2. **`lld-runner-build` tagged under `--profile engines`**: Inside `docker/lld-runner/Dockerfile` is `mvn dependency:go-offline`. Every time `--profile engines` was built with a pruned cache, Docker downloaded 500+ MB of Spring Boot and JUnit JARs from Maven Central inside Docker from scratch.
3. **`docker compose down` and `--force-recreate`**: Destroyed running PostgreSQL, MongoDB, Judge0, and Redis containers, forcing all databases to re-initialize and recreate schemas from scratch.
4. **`mvn clean`**: Deleted all pre-compiled classes on the host, preventing Maven from doing fast incremental compilation.

> [!TIP]
> `lld-runner-build` and `workspace-build` have been moved to `profiles: ["build-images"]`. They only need to be built once and will never be rebuilt during normal `--profile engines up` runs.
